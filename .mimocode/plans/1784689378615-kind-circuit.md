# 方案：布点说明自由编辑 + 生产环境分发

## 问题诊断

### 布点说明无法自由编辑的根本原因

`TextAnnotationShape.tsx:25` — `canEdit()` 返回 `false`，完全禁用了 tldraw 的内联编辑。用户唯一编辑入口是 Layout.tsx 顶部菜单的"编辑说明"按钮（触发模态弹窗），且每次重新布点时 `syncPointsToCanvas()` 会**静默删除并重建**说明形状，丢失用户手动编辑。

### 生产环境问题

- Canvas.tsx 的 `installDebug()` 在每次编辑器初始化时无条件运行，向 `window` 暴露调试函数
- Layout.tsx 在渲染函数体中直接调用 `getRecentProjects()`（读 localStorage + JSON.parse），拖拽时频繁触发
- electron/main.ts 缺少 CSP 安全策略
- 多处 console.error/console.warn 无用户反馈
- ZSlider 的 store listener 响应所有变更而非仅选择变更

## 第一部分：布点说明自由编辑

### 修改 1：`src/shapes/TextAnnotationShape.tsx`

**目标**：启用内联编辑（双击编辑），使用 foreignObject 模式（与 Chamber/ProbePoint 等形状一致）

```tsx
// 改动点：
// 1. canEdit() => true
// 2. 新增 component() 中的编辑态分支（foreignObject + textarea）
// 3. 新增 onEditStart() / onEditEnd() 生命周期
// 4. getGeometry() 保持 isFilled: true（点击不穿透）
// 5. 编辑态下 textarea 自动扩展宽度
```

具体变更：
- `canEdit()` 返回 `true`
- 添加 `isEditing` 辅助判断：通过 `this.editor.getEditingShapeId() === shape.id`
- 编辑态：渲染 `<foreignObject>` 包含 `<textarea>`，自动聚焦，内容双向绑定到 shape.props.content
- 非编辑态：保持现有 SVG `<text>` 渲染
- 添加 `onEditEnd()` 方法将 textarea 内容写回 shape props
- import 添加 `React` 用于 `useRef` 等

### 修改 2：`src/store/projectStore.ts`

**目标**：重新布点时保留用户手动编辑的说明

在 `syncPointsToCanvas()` 中：
- 执行前检查 existingDesc 是否被用户手动修改过（对比 `generatePlacementDescription` 的结果与当前 content）
- 如果用户修改过，弹出确认对话框：「说明已被手动编辑，是否保留？（保留/重新生成）」
- 保留模式：不删除 existingDesc，仅更新位置
- 重新生成模式：保持当前行为（删除 + 重建）

新增 store action `placementMode: 'keep' | 'regenerate'`，用户可在 AutoPlacePanel 中预设。

### 修改 3：`src/components/Layout.tsx`

- 删除 lines 48-55 的死代码（`'edit-description'` 事件监听器）
- `getRecentProjects()` 改为 `useMemo` 包裹，依赖可能变化的 key
- 编辑说明模态弹窗保留作为备用（长文本编辑场景），但不再是唯一入口

### 修改 4：`src/components/panels/AutoPlacePanel.tsx`

- 增加"保留说明"复选框，存储到 store 的 `placementMode`
- 移除 `confirm()` 弹窗，改为 toast 通知 + store 预设

### 修改 6：`src/components/Layout.tsx`（性能）

```tsx
// line 211: 从 render body 移入 useMemo

```

### 修改 7：`electron/main.ts`

添加 CSP header：
```ts
win.webContents.session.webRequest.onHeadersReceived((details, callback) => {
  callback({
    responseHeaders: {
      ...details.responseHeaders,
      'Content-Security-Policy': ["default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'"]
    }
  })
})
```

### 修改 8：`src/store/projectStore.ts`（错误处理）

将 `addPoint/removePoint/updatePoint/updatePointPosition` 中的 `console.error` 替换为 `showToast(msg, 'error')`。

### 修改 9：`src/components/ZSlider.tsx`

store listener 加过滤，只响应选择变化：
```ts
const unsub = editor.store.listen((entry) => {
  if (entry.type === 'change' && entry.source === 'selected' || ...) {
    const ids = editor.getSelectedShapeIds()
    setSelectedId(ids.length === 1 ? ids[0] : null)
  }
})
```
更精确的做法：使用 `editor.on('change', ...)` 并检查 `instance.pageShapeChange`。

添加 `dist-electron/`。

## 验证步骤

1. **内联编辑**：双击画布上的布点说明 → 应进入 textarea 编辑态 → 修改内容 → 点击外部 → 内容保存
2. **保留编辑**：手动修改说明 → 重新执行布点 → 应弹出 toast 提示 → 选择保留 → 说明不被覆盖
3. **导出验证**：PNG/SVG 导出时说明内容正确显示
4. **性能**：拖拽点位时 Layout 不再反复读取 localStorage
5. **生产构建**：`npm run electron:build` → 安装 → 运行 → 确认无 console.log/调试函数
6. **测试**：`npm test` 全部通过
